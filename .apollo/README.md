# Apollo

[`report.md`](report.md) was generated by **Apollo**, a CLI that checks this
repo's UIKit code against the specs in `cleverden/front-end-tech-specs/UIKIT`.
It is text processing only — no build, no simulator, no toolchain for any
platform, so one laptop produces the same report for Android, iOS and Web.

## Reproduce

```bash
git clone <cleverden>
cleverden/frontend-agentic/apollo/install.sh
apollo setup -g --clone
apollo doctor
apollo ground AmityMessageComposer AmityMessageBubble AmityChatPage
apollo check AmityMessageComposer AmityMessageBubble AmityChatPage --platform web -v
```

## Reading the report

| | meaning | what to do |
|---|---|---|
| `fail` | the spec says it, the code does not do it | fix the code |
| `warn` | the code does it, the spec does not say it | the spec is behind — raise it with the governance team |
| `info` | this platform has no mechanism for the contract | a migration, not a bug |

Apollo does not author or amend specs. `cleverden/frontend-governances` proves
PRD Hub → spec; Apollo proves spec → code, and reads their grounding verdict
rather than re-deriving it.
